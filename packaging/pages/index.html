Node Manager

A lightweight dashboard for running and monitoring cryptocurrency nodes.

Run Bitcoin, Monero, Tari, Litecoin, Dogecoin, Bitcoin Cash and Zcash from one small Go dashboard. Public runtime traffic stays behind Tor. The dashboard and optional node interfaces stay on your trusted LAN. Wallets are view-only: Node Manager never accepts a seed phrase or private spend key.
